What changed from v1

  • TENON is replaced by Vahl, designed from a study of 18 well-designed product sites, below.
  • Phones first. The main format is 4:5, with a rule that sets how close the camera must be for text to read on a phone. A 16:9 cut comes from the same script.
  • Captions talk to the viewer about Caret, never about the demo project, which stays unnamed on screen. They are drafts for you to edit.
  • No sound.
  • Fully simulated. Nothing runs the real app. Generated pictures, the sync's code change, the rebuilt section and the experiment takes are all staged for the films. The one rule kept: every behaviour shown is something Caret really does, in the order it does it.

The project on screen: Vahl

A fictional maker of carbon road and gravel bikes in Bergen. Its pages are real Caret design pages: React files in .caret/pages/, styled only with the foundation's tokens, with every visible element carrying a data-caret-id. They run unmodified in Caret's own canvas runtime, which is how the canvas shot below was made.

What the design borrows from the best product sites

  • The product and the weather are the hero, full-bleed (Scout Motors, Rivian, Snow Peak, Leica). No abstract artwork, no gradient blobs.
  • The model name used as type, not as a label (Rivian's R1S behind the car, Analogue's product names). STRAND is set 400px tall in Big Shoulders Display.
  • One signal colour, used once a screen (Rivian's yellow, Playdate's yellow). Vahl's is safety-vest orange, kept for the one action on each screen.
  • Plain, specific copy with numbers a rider checks (Teenage Engineering, Snow Peak): 6.9 kg, 34 mm, "ridden 20 km before it is boxed", a geometry table "so you can check their work".

Vahl's foundation

Fog paper neutral-100 Ink neutral-950 Signal brand-500 Big Shoulders Display for model names Schibsted Grotesk, 17px, ×1.333 Sharp corners, flat, 8px grid

Both typefaces are outside Caret's list of AI design habits, and both load through Caret's own font pipeline. The theme CSS was generated by Caret's own code from the foundation file, as the app would. Still to build after approval: Fjell (gravel), Journal, Fitting and Test ride, so the canvas has six pages in three groups.

Composed for phones

4:5 is the main film

1080×1350, rendered at 2160×2700 and 60fps. 4:5 fills most of a phone screen in X, LinkedIn and Instagram feeds and still sits well on desktop.

16:9 from the same script

1920×1080 for YouTube, the README and desktop. The camera follows the same subjects, framed wider.

A readability floor

Any text the viewer has to read is at least 34px tall on the 1080px frame, about 12pt on a phone. For Caret's 13px interface text, that means the phone frame shows at most about 410px of the window, which is roughly the width of the chat panel.

Wide shots are orientation only

The whole window appears for at most 1.2s and never carries text the viewer needs. Everything readable happens close up.

Captions at phone size

On the phone cut, captions sit in a band at the top of the frame at 52px semibold (about 19pt). On desktop they sit bottom-left at 40px. No text goes in the bottom 15% of the phone frame, where feed apps draw their buttons.

The first two seconds are the result

Every film opens on its payoff, because a phone viewer decides to keep watching before any setup has played.

What is staged

  • Generated photographs are Unsplash photographs, used under the Unsplash licence, which allows commercial use without credit. They arrive on the take board through the board's real states (waiting, making, ready).
  • The sync: the plan text, the tool rows and the change to the shop's Hero.tsx are written for the film, in the exact formats Caret's chat uses.
  • The rebuilt spec table, the three experiment takes and the rider quotes are real Vahl pages and sections I build, so they look exactly as finished work would.
  • The Vahl mark and the fog shader: the mark is drawn as SVG; the shader is real GLSL running in Caret's own shader preview component.
  • The code editor is a plain, unbranded editor drawn for the films, showing Vahl's real files.
